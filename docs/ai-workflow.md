# AI Workflow

## Intended Use

AI will be used for implementation volume, repetitive code generation,
debugging and QA assistance.

## Human-owned Decisions

- Scope and prioritisation
- Visual fidelity
- Shopify data modelling
- Component boundaries
- Accessibility decisions
- Final QA
- Deployment

## AI Review

AI-generated code will be checked against:
- supplied prototype
- Shopify requirements
- responsive behaviour
- theme-editor behaviour
- required edge cases

## Failure Tracking

During implementation I will record cases where AI:
- makes unsupported assumptions
- introduces unnecessary complexity
- reproduces prototype hardcoding instead of Shopify data
- produces visually inaccurate output
